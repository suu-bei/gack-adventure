## 為何不是全部重寫

缺圖、未使用檔案與影片來源失敗是不同問題。重寫主體不能證明能解決第三方來源限制，而且可能破壞已正常運作的動畫、貼紙與手機閱讀。因此保留已驗證內容與版面，集中處理載入、發布一致性、媒體狀態與錯誤恢復。

## V41 檔案結構

- index.html：唯一主入口，載入本版生成的 JS 與 CSS。
- assets/：帶內容雜湊名稱的執行檔，由 tools/build_release.py 產生。
- js/、css/、credits/：可維護原始碼，C 整合後產生 assets；不再逐檔由 index 混合載入。
- days/：四份原有 DAY 片段，維持獨立載入與 DOM 快取。
- images/：含 GitHub 原兩張貼紙及補齊的示範圖。
- players/：獨立原生影片外殼，按播放後才設置來源。
- data/release.json：本版檔案雜湊紀錄。
- check.html：獨立的上傳完整性檢查頁，不出現在一般閱讀流程。
- docs/、tools/：報告與可重建／檢查工具。

## 限制與尚未驗證

V41 的真實 X MP4 播放未確認成功。測試環境的 403 不表示所有使用者都被 X 阻擋，也不能當作使用者瀏覽器故障原因的定論。
YouTube／Drive 的嵌入畫面可在雲端瀏覽器出現，但完整有聲播放及所有平台的換日停止仍需要可播放的真實環境驗收。自動測試驗證的是暫停命令或卸載流程。
未使用實體 iPhone、Android 或 Safari。先前「測試通過」的聲明應理解為其記錄中明確列出的素材、瀏覽器與操作，不能擴大成所有真實影片均正常。
